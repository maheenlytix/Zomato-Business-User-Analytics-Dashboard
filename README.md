# Zomato Business & User Analytics Dashboard

An interactive Power BI dashboard designed to analyze Zomato's business performance, user activity and city-level insights.

## Project Overview

This project analyzes Zomato data across three key areas: overall business performance, user activity and city-level performance.

The dashboard provides insights into sales amount, quantity, orders, ratings and yearly sales trends.

It also analyzes active, gained and lost users along with user distribution by age.

City-level analysis helps compare sales, orders, ratings and active users across different locations.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization

## Features & Highlights

- Overall sales and order performance
- Year-wise sales analysis
- User activity and customer insights
- Gained and lost user analysis
- Age-wise user distribution
- City-wise sales performance
- City-wise order and rating analysis
- Active users by city
- Interactive city and metric filters

## Key Insights

- Analyzed overall sales, orders, quantity and ratings to understand business performance.
- Identified trends in sales across different years.
- Compared gained and lost users to understand user activity.
- Analyzed user distribution across different age groups.
- Compared cities based on sales, orders, ratings and active users.
- Identified high-performing cities across different business metrics.
